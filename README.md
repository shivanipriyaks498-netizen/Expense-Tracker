
# 💰 Expense Tracker

A responsive personal finance management application built using React. It helps users track daily expenses, manage monthly budgets, and understand spending habits through interactive charts.

## 🚀 Features

- Add, edit, and delete expenses
- Search expenses by name
- Filter expenses by category
- Monthly expense summary
- Monthly spending bar chart
- Category-wise pie chart
- Export expenses to CSV
- Monthly budget management
- Budget progress and overspending warning
- Date-range expense reports
- Save expense data using browser localStorage
- Responsive user interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Recharts
- Browser localStorage

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Expense-Tracker
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Create a production build

```bash
npm run build
```

## 💾 Data Storage

The application uses browser localStorage to save expenses and the monthly budget. Data is stored in the browser on the device being used.

## 🎯 Project Objective

The objective of this project is to develop a simple and user-friendly expense management system that helps individuals monitor their spending, maintain budgets, and make better financial decisions.
